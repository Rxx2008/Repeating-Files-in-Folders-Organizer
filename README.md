# Repeating-Files-in-Folders-Organizer
This program helps find and separate the same and different files into a new folder without doing action to the original files

You have two or more folders that contain some common files, and you want to pick them out? This program can help you do that!


Scenario 1:<br />
You are making a mod to make changes to the def files of a mod, and the mod you're making changes to was recently updated, and you're not sure which def files the author has changed or added. Put the two versions of def files into this application, and the files that are newly created would be separated out.

Scenario 2:<br />
You just finished wording in the map editor, and you are going to pick the sector files you need, which is a disaster to do. If you picked out the files before, you can put the europe folder in your new /user_map folder and your previous folder into this application, and the sectors would be sorted out. (If you worked on new sectors, you'll still have to manually pick them out)

# Note: this program uses a User Interface; below are the options' explanations of the UI:

Input: <br />
File A: files in folder A <br />
File B: files in folder B <br />

Output (in user-selected directory):<br />
Same in A: files in folder A that have the same file names as in folder B<br />
Same in B: files in folder B that have the same file names as in folder A<br />
Different in A: files in folder A that don't have the same file names as in folder B<br />
Different in B: files in folder B that don't have the same file names as in folder A<br />
